# 国际化

- 语言：英语 `en`，简体中文 `zh-Hans`
- 文件：`osmos-web/src/i18n.ts`
- 默认：URL `lang` 优先，其次 `localStorage`，最后浏览器语言
- 切换：底栏语言按钮
- URL：切换后写入 `lang=en` 或 `lang=zh`

覆盖范围。

- 页面标题和 `html lang`
- 品牌副标题
- 场景名称
- HUD 标签
- 质量、代、刻度、存活、颗粒、喷出物
- 检查面板标题、角色、谱系、质量、喷出、感知环、威胁、食物、控制输出、推力
- 暂停、继续、重置
- 场景、检查面板、速度组、画布和语言按钮的无障碍名称
- 加载错误和重试

场景 URL 参数仍是 `scenario=ambient|sentient|orbital|repulsor`，不随语言改变。

验证命令。

```bash
cd osmos-web
CHROME_PATH=/usr/bin/google-chrome VERIFY_INTERACTIONS=1 npm run verify:ui
```

交互日志会记录 `zhLang`、`zhBest`、`zhUrl`、`enLang`、`enBest` 和 `enUrl`。
