# 架构

## 范围

Osmos 是一个零玩家质量模拟。仿真在 Rust 中运行，通过 WebAssembly 暴露扁平快照，浏览器使用 SolidJS 和 Canvas 2D 显示。

## 数据流

```text
App -> Engine -> World -> Snapshot -> wasm -> Canvas 2D
```

- `App` 负责帧循环、渲染、交互和 URL 状态。
- `Engine` 维护基因组、世代和共享世界。
- 浏览器加载扁平冠军基因组。`Engine` 用 8 个精确副本和其余变异副本启动第一代。
- `World` 维护物理、碰撞、感知、喷出物和快照。
- `osmos-wasm` 把快照和检查数据转成 JavaScript 类型。

## Crate

- `osmos-core`：ID、向量、质量、半径、控制网络。
- `osmos-sim`：世界、质体、颗粒、碰撞、空间网格、场力、快照。
- `osmos-evo`：遗传算法、全学习者训练、共享世界。
- `osmos-wasm`：WebAssembly ABI。
- `osmos-headless`：训练、基准和留出种子复评。
- `osmos-web`：SolidJS 与 Canvas 2D 界面。

## 世界

- 默认场景为 64 个质体和 236 个颗粒，共 300 个实体。
- 场景 `Ambient`、`Sentient`、`Orbital` 和 `Repulsor` 都使用 64 个 AI，不生成脚本猎手或脚本猎物。
- `Sentient`、`Orbital` 和 `Repulsor` 使用 180 个颗粒。
- 仿真以 60 Hz 固定步长推进，内部使用 2 个物理子步。
- 位置位于单位环面。移动、距离、碰撞、场力和感知都使用最短环绕向量。
- 地图没有墙体。质体从右边离开后从左边出现，上下同理。

## 质量

- 质量是唯一资源。
- 半径由质量推导，`radius = 0.012 * sqrt(mass)`。
- 质量较大者渐进吸收较小者，没有 2 倍门槛。
- 每 60 Hz tick 转移一次。项目使用 2 个物理子步，因此每个子步转移一半。
- 转移比例等于半个弦长乘重叠深度，再除以小圆面积。
- 转移质量等于较小质量乘该比例，没有额外速率因子。
- 质量相等时按恢复系数 `0.8` 弹开。
- 质量低于 `0.05` 时不能推进。被吸收质体的剩余质量和动量并入吸收者。
- 颗粒和喷出物的吸收保持即时处理。总质量包含质体、待生成喷出物、颗粒、喷出物和颗粒储备。
- 颗粒储备初始为 `120` 质量。存活颗粒少于 `236` 个时从储备补充，储备耗尽后停止。

## 场力

`GravityWell` 提供中心径向加速度。

```text
acceleration = strength / max(distance, softening)^power
```

- 正强度吸引，负强度排斥。
- 指数 `power` 默认是 `2.0`，可配置。
- 软化半径为 `0.04`，用于限制近距离加速度。
- 最大加速度为 `0.12`，用于保持数值稳定。
- 井半径为 `0.045`，仅用于显示。
- 场力作用于质体和喷出物。
- `Orbital` 和 `Repulsor` 使用初始圆轨道速度。

## 空间网格与感知

- 空间网格为 `8 × 8`。
- 查询窗口为 `5 × 5`，覆盖 `0.25` 的感知半径。
- 感知输入为 55 个值。
- 前 48 个值是 16 个扇区，每个扇区包含质量差、接近度和径向速度。
- 第 48 到 54 个值是自身状态。
- 第 51 个值是最近更大质体的接近度。
- 第 53 个值是最近更小质体的接近度。
- 扇区方向和距离使用最短环绕向量。

## 控制与演化

- 控制网络为 `55-8-2`。
- 隐藏层和输出层使用 `tanh`。
- 基因组长度为 466。
- `Engine` 让全部 AI 质体使用控制网络。
- 后代按最终质量选择。死亡质体权重为 0。
- 质量概率选择亲本，子代经过交叉和变异。

## 快照

- 质体状态步长为 7。
- 颗粒状态步长为 4。
- 喷出物状态步长为 5。
- 场力井状态步长为 4，包含位置、半径和符号。
- 快照使用固定种子、固定遍历顺序和固定子步。

## 浏览器

- 所有场景使用同一 Canvas 2D 渲染路径。
- 支持选中质体、检查面板、暂停、1× 到 8× 和重置。
- 场景、种子和语言写入 URL。
- 界面支持英语和简体中文。
